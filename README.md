## 📖 项目简介

价值导向，是一切经济社会行为的指挥棒——无论政府、企业，还是个人、家庭。

本项目由**财情双生智库**（Econ-Sentiment Twin Think Tank）提出，历经 **10 多年**的博采众长、整合创新研发，将自然科学、社会科学、思维科学三大领域的整体最优解，转化为系统性的技术解决方案，形成独具特色的**产融联动、义利倍增**思想体系及实战方法。

在社会主义核心价值观下，本项目致力于从 0-1 创新经济社会核心基础科学，将「自私逐利的市场经济」与「强调集体利他的社会主义」纳入统一的价值内涵评估框架，形成一套上下贯通、宏观微观一致的**价值计量模型**，可解释西方主流经济学无法解释的原生经济现象，并以创造巨额价值增量为牵引，服务国家长治久安、企业基业长青、人民共同富裕。

> **The Law of Value Conservation** states that total economic-social value — the product of economic value, social value, and time value — remains constant over a given period. Value is neither created nor destroyed; it merely transforms or transfers. This project reconstructs the unified measure of economy and society, opening a new path for the unified market.

## ⚖️ 核心思想：价值守恒定律

纵观古今中外的几千年王朝更迭史、企业兴衰史、人物浮沉史，可以得出一个**价值总量守恒**的规律——在一定时期内：

### 宏观公式（经济社会治理）

$Y = E \times S \times T = \text{经济价值} \times \text{社会价值} \times \text{时间价值} = \text{经济社会价值总量}$

$Y = y_1 + y_2 + y_3 + \dots + y_n$

### 微观公式（个人、家庭、企业经营）

$y = f(m, h, t) = f(m) \times f(h) \times f(t)$

$= f(m)\ \text{货币价值} \times f(h)\ \text{幸福体验} \times f(t)\ \text{时间价值}$

正如自然界普遍存在的**能量守恒定律**：经济价值、社会价值既不会凭空产生，也不会凭空消失，只会从一种形式转化为另一种形式，或从一个主体转移到其它主体，而**价值的总量保持不变**。

### 定律说明

| 情形                | 结果                                                             |
| ----------------- | -------------------------------------------------------------- |
| 任一变量归 0 或为负       | 价值总量归 0 或为负：轻则人物沉沦、企业倒闭，重则经济社会动荡、国破家亡                          |
| 3 个变量均大于 1        | 进入发展期、扩张期                                                      |
| 任一变量处于 0–1 区间     | 进入收缩期、衰退期，破坏其余两个指标的价值                                          |
| 行为人无需对社会价值、时间价值负责 | 自发运用「除法公式」，牺牲社会价值与长期时间价值，追求短期经济价值最大化，导致市场经济盲目性、自发性、滞后性及周期性经济危机 |
| 幸福、高效、创增量         | 运用「乘法公式」，让工作过程也具备消费价值，双向循环，交替演进，创造工作动能                         |

## 🛠 技术说明

- **技术栈**：原生 HTML5 + CSS3 + JavaScript（ES6），无任何第三方框架与 CDN 依赖
- **公式系统**：Word OMML 数学公式经转换渲染为 HTML/CSS 公式结构
- **数据模型**：`structure.json` 以 `blocks`（段落块、公式块、图片块）与 `images`（资源映射）描述文档结构，可作为文档系统二次开发的数据源
- **兼容性**：支持现代浏览器（Chrome / Edge / Firefox / Safari）；移动端自适应
